# Airtime Arena

A portrait 3D trampoline competition inspired by the supplied Swim Racer video’s block-built athletes and stadium presentation. All models and arena art are original procedural geometry.

Hold the jump button to tuck. Release at the gold mark to extend and prepare to land. Three judged jumps determine your medal. Earn a medal to advance through City Qualifier, Sunset Open and Midnight Final. Space is an optional keyboard control.

Both HTML files embed the renderer and all art. Three.js is bundled under its MIT license. Open either file directly in a browser with WebGL. Progress saves after each landing. Reloading during a jump returns to the start of that jump.

GameWave lifecycle events follow actual routines. A confirmed like can unlock a gold uniform and a direct comment can unlock a finale decoration. The game also runs independently of the host.
